# MyBabyNotes Home Assistant add-on

Two-parent baby tracker in your Home Assistant sidebar — run it on the HA box
(`local` mode) or embed an existing instance (`remote` mode). See
[DOCS.md](DOCS.md) for setup and the
[main project](https://github.com/straplocked/mybabynotes) for everything else.

This directory is the add-on's source of truth; CI publishes it to
`straplocked/mybabynotes-hassio-addons` (the repository users actually add to
Home Assistant) on each tagged release.
